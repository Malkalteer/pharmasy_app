# نظام إدارة الصيدلية 💊

برنامج سطح مكتب لـ **Windows** لإدارة الصيدليات: البيع بالماسح الضوئي، المخزون والجرد، الدفعات وتواريخ الانتهاء، المشتريات والموردون، ديون الزبائن، الدرج المالي لكل صيدلي، التقارير والأرباح — مع تخزين محلي مشفّر وحماية ترخيص مربوطة بالجهاز.

مبني بـ **Flutter** (لغة Dart) حتى يمكن لاحقاً مشاركة الكود مع تطبيق الهاتف لصاحب الصيدلية.

---

## الميزات

### البيع (نقطة البيع)
- مسح الباركود مباشرة (أي ماسح USB يعمل كلوحة مفاتيح) أو البحث بالاسم / المادة الفعالة / الشركة.
- البيع بالعلبة أو الشريط (الظرف) أو الحبة، مع خصم صحيح من المخزون.
- البيع من الدفعة الأقرب انتهاءً أولاً (FEFO) ومنع بيع المنتهي.
- اقتراح **البدائل** (نفس المادة الفعالة) تلقائياً عند نفاد الدواء.
- الدفع بالليرة السورية و/أو الدولار مع حساب الباقي، أو تسجيل الباقي ديناً على الزبون.
- طباعة الفاتورة على طابعة حرارية 80/58 مم أو A4/A5.
- اختصارات: `F2` البحث، `F12` الدفع، `Esc` مسح البحث، `Enter` في حقل فارغ = الدفع.

### التسعير بالدولار
- كل الأسعار تُسجَّل **بالدولار**، وسعر الليرة = السعر × سعر الصرف الذي يحدده المدير.
- مثال: دواء بـ 2$ وسعر الصرف 150 ← يُباع بـ 300 ل.س.
- تقريب قابل للتعديل (لأقرب 1/5/10/25/50/100/500 ليرة، للأقرب أو للأعلى أو للأدنى).
- سجل لتغييرات سعر الصرف.

### المخزون
- الدفعات (Batches) مع رقم التشغيلة وتاريخ الانتهاء وسعر التكلفة لكل دفعة.
- تنبيهات الانتهاء (شهر / 3 / 6 أشهر / سنة) وإتلاف المنتهي.
- حد أدنى لكل دواء + **قائمة نواقص** جاهزة للنسخ إلى واتساب أو الطباعة للمستودع.
- الجرد وتعديل الكميات (جرد، تالف، منتهي) مع تسجيل السبب.

### المشتريات والموردون
- فواتير شراء مع البونص والخصم وتحديث سعر البيع مباشرة.
- حساب كل مورد (المستحق، الدفعات بالليرة أو الدولار، من الدرج أو من خارجه).
- مرتجع إلى المورد (خصم من الحساب أو استلام نقدي).

### الزبائن والديون
- البيع بالدين مع سقف دين اختياري لكل زبون.
- كشف حساب، تحصيل دفعات، تسويات (للمالك فقط).
- الديون محفوظة بما يعادلها **بالدولار** لحماية الصيدلية من تغيّر سعر الصرف.

### المرتجعات
- مرتجع من زبون برقم الفاتورة: تُعاد الكمية للمخزون (أو لا، إن كان تالفاً)، ويُخصم من دين الفاتورة أولاً ثم يُعاد الباقي نقداً.

### الدرج المالي والورديات
- كل صيدلي يدخل بحسابه ويفتح **وردية** بدرج خاص به.
- كل حركة نقدية مسجلة: مبيعات، باقي، مرتجعات، مصاريف، سحب، إيداع، تحصيل ديون، دفعات موردين.
- **تسليم الدرج**: البرنامج يعرض المبلغ المتوقع (ليرة ودولار)، والصيدلي يُدخل المبلغ الفعلي، فيُسجَّل الفرق (عجز أو زيادة) ويُصفَّر الدرج ويُطبع تقرير التسليم.

### المستخدمون والصلاحيات
- **المالك**: كل الصلاحيات.
- **الصيدلي**: يبيع دائماً، ويمكن منحه صلاحيات محددة: تعديل الأسعار، إدارة الأدوية، المشتريات، الديون، البيع بالدين، الخصم، إلغاء الفواتير، المرتجعات، التقارير، المصاريف...
- **سجل العمليات (Audit Log)**: من عدّل سعراً، من ألغى فاتورة، من عدّل الجرد، محاولات الدخول الفاشلة... ومتى.

### التقارير
- لوحة اليوم: المبيعات، الربح، الورديات المفتوحة وما في كل درج، النواقص، الانتهاء، الديون.
- تقارير يومية وشهرية: المبيعات، المرتجعات، التكلفة، **الربح** ونسبته، الأكثر مبيعاً، حسب الصيدلي، المصاريف.

### النسخ الاحتياطي
- نسخة تلقائية يومية داخل مجلد البرنامج (يحتفظ بآخر 30 نسخة).
- نسخة إضافية إلى مجلد خارجي: **فلاشة USB** أو مجلد **Google Drive / OneDrive** (فتصبح نسخة سحابية تلقائياً).
- استعادة نسخة من الإعدادات.

### الحماية
- قاعدة البيانات **مشفّرة** (SQLite3 Multiple Ciphers) ولا تُفتح خارج البرنامج.
- البرنامج يعمل فقط بـ **كود تفعيل** موقّع رقمياً (Ed25519) ومربوط **ببصمة الجهاز** (اللوحة الأم والمعالج).
- دعم الاشتراكات محددة المدة، مع حماية من إرجاع تاريخ الجهاز.
- تشويش الكود عند البناء (`--obfuscate`)، ومنع تشغيل نسختين في نفس الوقت.

## نظام التراخيص (لك أنت كبائع)

### مرة واحدة فقط: توليد مفاتيحك
```bash
dart run tool/license_tool.dart keygen
```
- ينشئ **المفتاح الخاص** في `keys/license_private.key`. احتفظ بنسخة منه على فلاشة في مكان آمن. **لا ترفعه إلى GitHub** (المجلد `keys/` مستثنى في `.gitignore`).
- يحدّث `lib/core/license/public_key.dart` بالمفتاح العام. ارفع هذا الملف، فهو آمن.

> ⚠️ إذا ضاع المفتاح الخاص لن تستطيع إصدار تراخيص جديدة، وإذا تسرّب يستطيع غيرك إصدارها.

### لكل صيدلية جديدة
1. الصيدلية تثبّت البرنامج، فتظهر شاشة التفعيل وفيها **رمز الجهاز** (مثل `044B-CC0E-00DE-1D24-708E`).
2. ترسل لك الرمز، فتولّد الكود:
   ```bash
   # ترخيص دائم
   dart run tool/license_tool.dart sign --machine 044B-CC0E-00DE-1D24-708E --name "صيدلية الشفاء"
   # اشتراك حتى تاريخ معين
   dart run tool/license_tool.dart sign --machine 044B-CC0E-00DE-1D24-708E --name "صيدلية الشفاء" --expires 2027-12-31
   ```
3. ترسل لها الكود فتلصقه في البرنامج. كل التراخيص تُسجَّل في `keys/issued_licenses.csv`.

نسخ البرنامج إلى جهاز آخر لا يفيد، لأن الكود مربوط برمز الجهاز.

> في وضع التطوير (`flutter run`) يعمل البرنامج بدون ترخيص ويظهر "نسخة تطوير". نسخة الإصدار (Release) تتطلب الترخيص دائماً.

## بناء ملف التنصيب (Setup.exe)

ملف التنصيب يحتوي **كل شيء**: البرنامج، مكتبة قاعدة البيانات المشفرة، الخطوط العربية، ومكتبات Visual C++. لا يحتاج إنترنت ولا أي تثبيت إضافي على جهاز الصيدلية (Windows 10/11 بنظام 64 بت).

### الطريقة 1: تلقائياً على GitHub
أنشئ tag للإصدار:
```bash
git tag v1.0.0
```
```bash
git push origin v1.0.0
```
سيبني GitHub Actions ملف `PharmacyManager-Setup-1.0.0.exe` وتجده في صفحة **Actions ← Artifacts**. يمكن أيضاً تشغيله يدوياً من Actions ← Build Windows ← Run workflow.

### الطريقة 2: على جهاز Windows
المتطلبات: [Flutter](https://docs.flutter.dev/get-started/install/windows/desktop)، و Visual Studio (مع "Desktop development with C++")، و [NSIS 3](https://nsis.sourceforge.io/Download) (مجاني حتى للاستخدام التجاري).
```bat
installer\build_installer.bat 1.0.0
```
الناتج: `build\installer\PharmacyManager-Setup-1.0.0.exe`

إذا كان البرنامج مبنياً مسبقاً وتريد إعادة صنع ملف التنصيب فقط:
```bat
installer\build_installer.bat 1.0.0 skipbuild
```

> لا تنسَ تشغيل `keygen` ورفع `public_key.dart` **قبل** بناء النسخة التي ستبيعها.

## التطوير

```bash
flutter pub get
```
```bash
flutter run -d windows
```
```bash
flutter test
```
بيانات تجريبية للعرض (على قاعدة بيانات فارغة، المستخدمون `admin` و `ahmad` وكلمة المرور `1234`):
```bat
set PHARMACY_DEMO=1
```
```bat
flutter run -d windows
```
بعد تعديل جداول قاعدة البيانات في `lib/data/tables.dart`:
```bash
dart run build_runner build --delete-conflicting-outputs
```

### هيكل المشروع
```
lib/
  core/        المال والتقريب، الوحدات، الصلاحيات، حالة البرنامج، الترخيص
  data/        جداول قاعدة البيانات (Drift + SQLite مشفّرة)
  services/    منطق العمل: البيع، المخزون، الورديات، الديون، المشتريات، المرتجعات، التقارير، النسخ الاحتياطي
  printing/    الفواتير والتقارير (PDF عربي)
  ui/          الواجهات (عربي، من اليمين لليسار)
tool/          أداة توليد التراخيص
installer/     ملف التنصيب (NSIS) وسكربت البناء
test/          اختبارات منطق العمل والطباعة
```

مكان بيانات الصيدلية على Windows: `%APPDATA%\com.pharmasy\Pharmacy Manager\` (لا تُحذف عند إلغاء التثبيت).

## المرحلة القادمة: تطبيق الهاتف لصاحب الصيدلية
الهاتف لا يستطيع الاتصال مباشرة بقاعدة بيانات على لابتوب الصيدلية، فالخطة:
1. البرنامج يرفع ملخصات (المبيعات، المخزون، الورديات، النواقص) إلى سيرفر سحابي (مثل Supabase) عند توفر الإنترنت، ويبقى يعمل بالكامل بدونه.
2. تطبيق Flutter للهاتف يقرأ من السيرفر، ويمكن أن يكون اشتراكاً شهرياً مدفوعاً.
3. التحقق الدوري من الترخيص عبر نفس السيرفر.
